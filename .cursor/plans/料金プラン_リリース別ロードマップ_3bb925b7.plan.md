# 料金プラン リリース別ロードマップ

## 基本方針

元の計画（[ai読み込み・公開機能プラン](c:\Users\nanoha.cursor\plans\ai読み込み・公開機能プラン_2df1e5c5.plan.md)）からの変更点:

- **追加パック** → **買い切りパック**（メインの有料入口に昇格）
- 買い切りは **失効なし**（使い切るまで残る）、ただし **サブスクより割高**
- ファネル: **フリー → 買い切りで試す → 毎月使うならサブスクがお得**
- AI機能の種類に関係なく **1回=1カウント** は変更なし
- 課金単位は **Group（世帯）** のまま
- **内税**（消費税10%込み）
- **Stripe 最低手数料120円** を考慮し、最低商品価格は400円以上に設定
- **Phase1 OCR を Google Cloud Vision API に切り替え済み** — レシピ読み込みの原価が約3円→約2円に改善（月1,000回まで無料枠あり）

## 買い切りパックの設計詳細

### 残高管理

- `groups` テーブルに `ai_credit_balance`（買い切り残高）カラムを追加
- 購入するたびに残高に加算（失効なし）
- 消費順序: **サブスク月間枠 → 買い切り残高** の順で消費

### 消費順序のUX（確定: 消費元の常時表示 + 切り替わり通知）

サブスク枠と買い切り残高の2つのプールがあるため、「なぜか買い切りが減っている」という混乱を防ぐ必要がある。

**方針: 消費元の透明性を UI で担保する**

1. **消費元の常時表示**: AI機能の利用後や残回数表示で、常にどちらの残高から消費されたかを明示する
   - 例: 「サブスク: 残り22/30回 | パック: 8回」
   - どちらが減ったか一目でわかる状態を維持
2. **切り替わり時の1回通知**: サブスク月間枠がゼロになり、買い切り残高からの消費に切り替わったタイミングで通知を1回表示する
   - 例: 「今月のサブスク枠を使い切りました。以降は買い切り残高から消費されます」
   - 毎回ではなく**切り替わり時の1回だけ**（煩わしさを抑える）
3. **毎回の選択は不要**: 消費順序は自動（サブスク → 買い切り）のまま。ユーザーに毎回選ばせると操作が煩雑になるため採用しない

### サブスク加入者と買い切りの関係

- サブスク加入者も買い切り購入可能（月間枠を超えた分に使える）
- サブスク解約後も買い切り残高は残る（失効しない）
- サブスク月間枠はリセット、買い切りは減らない

### API パス（命名）

元の `10` / `30` から **スラッグ名** に変更:

- `POST /billing/packs/light` → ライト（10回）
- `POST /billing/packs/value` → バリュー（30回）

### Stripe 商品構成

| Stripe Price              | 種類                | meap 側の対応        |
| ------------------------- | ------------------- | -------------------- |
| `STRIPE_PRICE_STANDARD`   | recurring (monthly) | スタンダードサブスク |
| `STRIPE_PRICE_PACK_LIGHT` | one_time            | 買い切りライト       |
| `STRIPE_PRICE_PACK_VALUE` | one_time            | 買い切りバリュー     |

## コスト管理方針（確定: アプローチ 1+2+3）

「1回=1カウント」のシンプルさを維持しつつ、機能単位での赤字を防ぐ。

### 方針の全体像

| #   | アプローチ             | 内容                                       | コード影響                       |


## 損益シミュレーション

### 計算式

```
固定費 = 消費税（売上 × 10/110）+ Stripe 手数料
AI予算 = 売上 − 固定費          ← AI原価に使える上限額
手残り = AI予算 − AI原価
利益率 = 手残り ÷ 売上
```

Stripe 手数料:
- 買い切り: max(売上 × 3.6%, 120円)
- サブスク: max(売上 × 3.6%, 120円) + 売上 × 0.7%

### 機能別AI原価

| AI機能         | 原価/回 | 利用可能プラン       |
| -------------- | ------- | -------------------- |
| レシピ読み込み | 2円     | 全プラン             |
| レシピ提案     | 3円     | 全プラン             |
| 画像生成       | 10円    | プロ以上 / 買い切り  |
| 献立提案       | 5円     | プロ+のみ / 買い切り |

※ レシピ読み込みは Google Cloud Vision API（Phase1 OCR・月1,000回無料）+ GPT-4o テキスト（Phase2 構造化）の合計原価。
