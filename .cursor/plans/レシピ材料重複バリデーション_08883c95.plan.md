# レシピ材料の重複バリデーション追加

## 背景

レシピの `ingredients` 配列に、同じ材料名＋同じ単位の組み合わせが複数行入ることを防ぎたい。現状はどちらの層にも重複チェックがない。

## 重複の定義

同一レシピ内で `**name` と `unitId` が同じ 材料行が2つ以上あれば重複とする。

- 例: 「米 / 合」が2行 → 重複
- 例: 「米 / 合」と「米 / g」 → 別物（単位が異なる）

## 変更箇所

### 1. サーバー側 — FormRequest の `withValidator` に重複チェックを追加

対象ファイル:

- [RecipeStoreRequest.php](server/app/Http/Requests/Api/RecipeStoreRequest.php) — `withValidator` メソッド内
- [RecipeUpdateRequest.php](server/app/Http/Requests/Api/RecipeUpdateRequest.php) — 同上

既存の `withValidator` の `$validator->after(...)` コールバック内に、`ingredients` 配列を走査して `name + unitId` の組み合わせが重複していないかチェックするロジックを追加する。

```php
// 既存の foreach ループの後に追加
$seen = [];
foreach ($ingredients as $index => $ingredient) {
    $key = ($ingredient['name'] ?? '') . '|' . ($ingredient['unitId'] ?? '');
    if (in_array($key, $seen, true)) {
        $validator->errors()->add(
            "ingredients.{$index}.name",
            __('validation.duplicate_ingredient')
        );
    }
    $seen[] = $key;
}
```

翻訳メッセージ `validation.duplicate_ingredient` を `lang/ja/validation.php` に追加する。

### 2. クライアント側 — レシピ送信前に重複チェック

対象ファイル:

- [useRecipeEditForm.ts](client/src/models/recipe/hooks/useRecipeEditForm.ts) — `onSubmit` または `isDisabledSendButton` 周辺

`formatIngredientItems` で空行を除外した後の `ingredients` に対して、`name + unitId` の重複があればエラーを `errors` state にセットし、送信を防ぐ。既存の `errors` / `setErrors` の仕組みをそのまま活用する。
