# トレイトテストケース詳細仕様

## 概要

`LoggingTrait`と`ExceptionHandlerTrait`の動作を検証するための包括的なテストスイートを作成しました。各テストケースは、特定の入力に対して期待される出力を明確に定義し、トレイトの動作を詳細に検証します。

## テストファイル構成

### 1. LoggingTraitTest.php - 基本動作テスト

### 2. ExceptionHandlerTraitTest.php - 例外処理テスト

### 3. LoggingIntegrationTest.php - 統合テスト

## テスト実行方法

### Sail 環境での実行

```bash
cd server
chmod +x tests/sh/test-logging.sh
./tests/sh/test-logging.sh
```

### 個別テストの実行

```bash
# 特定のテストファイルのみ実行
./vendor/bin/sail artisan test tests/Feature/LoggingTraitTest.php

# 複数のテストファイルを実行
./vendor/bin/sail artisan test --filter="LoggingTraitTest|ExceptionHandlerTraitTest|LoggingIntegrationTest"
```

### ログ出力の確認

```bash
# リアルタイムでのログ確認
tail -f storage/logs/laravel.log

# 特定のログレベルの確認
grep 'ERROR' storage/logs/laravel.log
grep 'INFO' storage/logs/laravel.log
grep 'WARNING' storage/logs/laravel.log
```

## テスト設計のポイント

### 1. 段階的な検証

-   単体テスト（LoggingTraitTest）→ 統合テスト（LoggingIntegrationTest）の順序
-   各テストケースで特定の機能に焦点を当てた検証

### 2. 実際のログ出力確認

-   モックを使用した単体テストと、実際のファイル出力を確認する統合テストの併用
-   本番環境での動作を事前に検証

### 3. 機密情報の適切な処理

-   パスワード、トークンなどの機密情報が適切にフィルタリングされることを確認
-   非機密情報が正しく記録されることを確認

### 4. 例外処理の統合

-   各種例外が適切に処理され、適切な HTTP ステータスコードが返されることを確認
-   例外発生時のログ記録が適切に行われることを確認

このテストスイートにより、トレイトの動作を包括的に検証し、本番環境での安定性を確保できます。
