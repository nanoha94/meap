# InvitationTokenCleanup テストケース詳細仕様

## 概要

期限切れ招待トークンの日次削除（`routes/console.php`）を検証する。参加成功時にはトークンを削除せず、有効期限切れの行だけを毎日掃除する。

## テストケース一覧表

| ID    | テスト名                                                     | 種別   | 入力条件                                           | 期待される出力                                         | 該当メソッド          |
| ----- | ------------------------------------------------------------ | ------ | -------------------------------------------------- | ------------------------------------------------------ | --------------------- |
| 8-1-1 | 【期限切れ削除】 日次スケジュールで期限切れトークンのみ削除される | 正常系 | 期限切れトークンと有効なトークンが各1件存在する    | 期限切れのみ削除され、有効なトークンは残る。スケジュールは daily | `Schedule::call()` |

## テスト実行方法

### Sail 環境での実行

```bash
cd server
./vendor/bin/sail test tests/Feature/Console/InvitationTokenCleanupTest.php --stop-on-failure
```
