## 概要

Auth 関連のコントローラーテストファイル群で実装されている認証機能の包括的なテストスイートの詳細仕様です。ログイン、ログアウト、ユーザー登録、メール認証、パスワードリセット機能の動作を詳細に検証し、認証システムの安定性と安全性を確保します。

## テストファイル構成

### Auth 関連テストファイル一覧

#### AuthenticatedSessionControllerTest.php - セッション認証テスト

-   ログイン機能のテスト
-   ログアウト機能のテスト
-   セキュリティ機能のテスト
-   バリデーション機能のテスト
-   異常系・セキュリティ攻撃のテスト
-   パフォーマンス・リソース管理のテスト

#### VerifyEmailControllerTest.php - メール認証テスト

-   メール認証機能のテスト
-   認証リンクの検証テスト

#### PasswordResetLinkControllerTest.php - パスワードリセットリンクテスト

-   パスワードリセットリンク要求のテスト
-   パスワードリセット実行のテスト

#### RegisteredUserControllerTest.php - ユーザー登録テスト

-   新規ユーザー登録機能のテスト
-   登録バリデーションのテスト

## テストケース体系化

### テストケース種別について

| 種別         | 説明                         | 対象テスト                           |
| ------------ | ---------------------------- | ------------------------------------ |
| 正常系       | 期待される正常な動作を検証   | ログイン成功、Remember Me 機能       |
| 異常系       | エラー条件での動作を検証     | 無効な認証情報、バリデーションエラー |
| セキュリティ | セキュリティ機能の動作を検証 | レート制限、SQL インジェクション防止 |
| ログアウト   | ログアウト機能の動作を検証   | 正常ログアウト、未認証ユーザーの処理 |

### 1. 正常系テスト

| ID  | テスト名         | 種別   | 入力条件       | 期待結果              | 検証ポイント     |
| --- | ---------------- | ------ | -------------- | --------------------- | ---------------- |
| 1-1 | 正常ログイン     | 正常系 | 有効な認証情報 | HTTP 200 JSON success | 認証成功時の挙動 |
| 1-2 | Remember Me 機能 | 正常系 | remember=true  | 永続クッキー設定      | セッション持続   |

### 2. 異常系テスト

| ID  | テスト名       | 種別   | 入力条件         | 期待結果 | 検証ポイント       |
| --- | -------------- | ------ | ---------------- | -------- | ------------------ |
| 2-1 | 無効な認証情報 | 異常系 | 誤ったパスワード | HTTP 302 | エラーハンドリング |

### 3. セキュリティテスト

| ID  | テスト名                 | 種別         | 入力条件      | 期待結果 | 検証ポイント         |
| --- | ------------------------ | ------------ | ------------- | -------- | -------------------- |
| 3-1 | SQL インジェクション攻撃 | セキュリティ | ' OR 1=1 --   | HTTP 302 | インジェクション防止 |
| 3-2 | レート制限               | セキュリティ | 連続 6 回失敗 | HTTP 429 | アカウントロック     |

### 4. ログアウトテスト

| ID  | テスト名         | 種別       | 入力条件 | 期待結果 | 検証ポイント     |
| --- | ---------------- | ---------- | -------- | -------- | ---------------- |
| 4-1 | 正常ログアウト   | ログアウト | 認証済み | HTTP 200 | セッション無効化 |
| 4-2 | 未認証ログアウト | ログアウト | 未認証   | HTTP 302 | リダイレクト     |

## テスト実行方法

### Sail 環境での実行

```bash
cd server
./tests/sh/01_run_auth_tests.sh
```

### 認証テストのみ実行

```bash
# 特定のテストファイルのみ実行
./vendor/bin/sail artisan test tests/Feature/Auth/AuthenticatedSessionControllerTest.php
./vendor/bin/sail artisan test tests/Feature/Auth/VerifyEmailControllerTest.php
./vendor/bin/sail artisan test tests/Feature/Auth/PasswordResetLinkControllerTest.php
./vendor/bin/sail artisan test tests/Feature/Auth/RegisteredUserControllerTest.php

# 認証関連のテストのみ実行
./vendor/bin/sail artisan test --filter="AuthenticatedSessionControllerTest"
./vendor/bin/sail artisan test --filter="VerifyEmailControllerTest"
./vendor/bin/sail artisan test --filter="PasswordResetLinkControllerTest"
./vendor/bin/sail artisan test --filter="RegisteredUserControllerTest"

# Authディレクトリ内の全テストを実行
./vendor/bin/sail artisan test tests/Feature/Auth/
```

## 推奨追加テストケース

### 優先度別追加ケース

| ID  | テスト名               | 検証内容         | 優先度 | 理由                     |
| --- | ---------------------- | ---------------- | ------ | ------------------------ |
| 1   | 長いパスワード処理     | 文字数制限確認   | 中     | 文字数制限の確認         |
| 2   | 特殊文字サニタイズ     | セキュリティ強化 | 中     | セキュリティ強化の確認   |
| 3   | 同時ログイン試行       | 並行処理確認     | 中     | 並行処理での動作確認     |
| 4   | セッションタイムアウト | セッション管理   | 低     | セッション管理機能の確認 |
| 5   | パスワードリセット     | 認証フロー完全性 | 低     | 認証フローの完全性確認   |

### 実装時の考慮事項

-   **文字数制限テスト**: データベースのカラム制限とフロントエンドのバリデーションの整合性確認
-   **特殊文字サニタイズ**: XSS 攻撃の防止とユーザー入力の適切な処理確認
-   **並行処理テスト**: レート制限機能との整合性とパフォーマンスへの影響確認
-   **セッション管理**: セキュリティポリシーとの整合性とユーザー体験への影響確認
