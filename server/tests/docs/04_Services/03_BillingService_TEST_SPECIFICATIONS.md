# BillingService テストケース詳細仕様

## 概要

PAY.JP 連携によるカード更新・削除、サブスクリプション開始・解約、買い切りパック購入、課金状態取得、解約予定取り消し、請求履歴取得を担う `BillingService` の単体テスト。`PayjpBillingClient` をモックし、Group / subscription レコードの更新と返却配列・例外条件を検証する。

## テスト方針

- PAY.JP API への実通信は行わない
- `config('billing.subscription_plan_ids.standard')` / `billing.subscription_amounts.standard` / `billing.pack_prices.*` はテスト用の固定値を設定する
- Group は `payjp_customer_id` および subscriptions テーブル（`payjp_subscription_id` / `status` / `ends_at` / `current_period_end` 等）で課金状態を表現する
- カード有効期限（`pm_exp_month` / `pm_exp_year`）はカード登録・更新時に Group へ保存し、`getBillingStatus()` は PAY.JP へ問い合わせない
- `getInvoices()` は DB 上の subscription から upcomingInvoice を組み立て、`listCharges()` の結果から pastInvoices を組み立てる
